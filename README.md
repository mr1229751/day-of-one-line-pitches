A single line for make.fun's “A Day of One-Line Pitches” bounty (240 characters at most): “You tell your phone what to play and your maps where to go — on make.fun you describe the app in your head in plain words, watch an AI build it, and keep it or change it: no code, and nothing to lose but the idea staying in your head.” The line is 234 characters. A tiny deterministic Node program writes exactly that line to the entry file and guards the gate itself: 1–240 characters, a single line, never only whitespace. It was picked by an adversarial criteria critique over 7 candidates, strongest on the judge's first criteria in order.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
